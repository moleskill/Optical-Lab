# Optical Lab Studio

Optical Lab Studio — интерактивная виртуальная лаборатория по геометрической оптике, разработанная с использованием HTML, CSS и JavaScript.

Проект позволяет проводить виртуальные эксперименты со светом, исследовать отражение, преломление и дисперсию, а также изучать работу зеркал, линз и призм непосредственно в браузере.

## Возможности

- Создание и настройка лазерных источников света.
- Моделирование отражения света от плоских зеркал.
- Использование собирающих и рассеивающих линз.
- Исследование преломления света в стеклянных блоках.
- Наблюдение дисперсии белого света с помощью призмы.
- Изменение угла, размера и показателя преломления объектов.
- Настройка количества и цвета световых лучей.
- Использование линейки и транспортира.
- Отображение нормалей к оптическим поверхностям.
- Готовые эксперименты для изучения оптических явлений.
- Отмена и повторение действий.
- Сохранение и загрузка экспериментов в формате JSON.
- Поддержка светлой и тёмной тем оформления.

## Установка и запуск

1. Скачайте исходный код проекта.
2. Распакуйте архив в отдельную папку.
3. Убедитесь, что файлы `index.html`, `style.css` и `script.js` находятся в одной директории.
4. Откройте `index.html` в современном браузере.

Для работы приложения не требуется установка дополнительных зависимостей или запуск сервера.

## Доступные эксперименты

### 1. Отражение света

Исследование отражения светового луча от плоского зеркала. Пользователь может изменять угол наклона зеркала и наблюдать изменение направления отражённого луча.

### 2. Преломление света

Изучение изменения направления света при переходе из воздуха в стекло и обратно. Можно изменять показатель преломления материала.

### 3. Собирающая линза

Исследование прохождения световых лучей через собирающую линзу. При первом запуске симулятора используется один световой луч, но его количество можно изменить.

### 4. Дисперсия света

Моделирование прохождения белого света через призму и разделения его на спектральные компоненты.

## Управление

Для добавления объекта необходимо выбрать соответствующий инструмент на боковой панели и нажать на рабочую область.

Объекты можно перемещать с помощью мыши. После выделения объекта становятся доступны настройки его параметров.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl + Z | Отмена действия |
| Ctrl + Y | Повтор действия |
| Ctrl + Shift + Z | Повтор действия |
| Delete | Удаление выделенного объекта |
| Escape | Снятие выделения |
| V | Выбор инструмента выделения |

## Физическая основа

В основе симулятора лежат законы геометрической оптики.

### Закон отражения

Угол падения светового луча равен углу отражения.

### Закон преломления

Для расчёта направления преломлённого луча используется закон Снеллиуса:

n₁ · sin(θ₁) = n₂ · sin(θ₂)

где n₁ и n₂ — показатели преломления двух сред, а θ₁ и θ₂ — углы падения и преломления соответственно.

Также реализована упрощённая модель дисперсии, учитывающая зависимость показателя преломления от длины волны.

Симулятор предназначен для образовательных целей. Некоторые физические процессы представлены приближённо.

## Процесс разработки

Проект создавался с целью разработать доступную интерактивную среду для изучения геометрической оптики без использования специализированного оборудования.

В процессе разработки основное внимание уделялось визуализации световых лучей, реализации физических законов, удобству интерфейса и взаимодействию с оптическими объектами.

Для исправления некоторых ошибок использовался ChatGPT. В частности, он помогал находить синтаксические ошибки CSS, такие как пропущенные точки с запятой, а также решать отдельные проблемы в коде.

### Проблемы с Hackatime

Во время разработки возникли трудности с настройкой Hackatime.

Несмотря на то что установка выглядела успешной и на проект было потрачено несколько часов работы, в панели Hackatime отображались только две минуты активности.

Кроме того, зарегистрированная активность не была корректно привязана к папке проекта. Возможной причиной могла стать работа в среде WSL2, однако точная причина проблемы не установлена.

Поэтому отображаемая статистика Hackatime не соответствует фактическому времени разработки.

## Цель проекта

Главная цель Optical Lab Studio — сделать изучение геометрической оптики более доступным, наглядным и интерактивным.

Проект демонстрирует, как с помощью стандартных веб-технологий можно создать образовательный инструмент для проведения виртуальных физических экспериментов.
